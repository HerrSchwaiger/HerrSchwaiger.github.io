Information

Der Aufbau eines Java-Programms

Jedes Java-Programm braucht mindestens eine Klasse und darin eine ganz bestimmte Methode, die main-Methode. Sie ist die Stelle, an der das Programm zu laufen beginnt.

Fahrt mit der Maus über die unterstrichenen Stellen im folgenden Code, um zu sehen, welche Aufgabe sie haben.

public class HalloWelt {
    public static void main(String[] args) {
        System.out.println("Hallo Welt");
   }
}

Wichtig ist dabei die genaue Schreibweise: Jede Anweisung endet mit einem Semikolon ;, und geschweifte Klammern { } markieren zusammengehörige Blöcke. Der Klassenname muss außerdem exakt mit dem Dateinamen übereinstimmen -- aus HalloWelt wird also die Datei HalloWelt.java.

Ausgabe: print vs. println

System.out.println(...) gibt den Text aus und springt danach in eine neue Zeile.

System.out.println("Erste Zeile");
System.out.println("Zweite Zeile");
Erste Zeile
Zweite Zeile

System.out.print(...) gibt den Text aus, bleibt danach aber in derselben Zeile.

System.out.print("Erste ");
System.out.print("Zweite");
Erste Zweite

Text, der ausgegeben werden soll, steht in Java immer in doppelten Anführungszeichen. Man nennt diesen Text eine Zeichenkette oder String.

Erste Fehlermeldungen lesen

Beim Programmieren gehören Fehler zum Alltag -- auch bei erfahrenen Entwicklerinnen und Entwicklern. Wichtig ist, die Fehlermeldung von NetBeans lesen zu können, statt sie zu ignorieren.

System.out.println("Hallo Welt")

NetBeans meldet sinngemäß ';' expected. Das bedeutet: An dieser Stelle fehlt ein Semikolon am Ende der Zeile.

Meldet NetBeans reached end of file while parsing, fehlt meist eine schließende Klammer }. Zählt geschweifte Klammern paarweise, um die fehlende Stelle zu finden.

Meldet NetBeans unclosed string literal, fehlt ein schließendes Anführungszeichen bei einem Text in Anführungszeichen.

Code Lückentext

Vervollständigt das Programm, indem ihr die fehlenden Stellen ausfüllt, und klickt danach auf Überprüfen.

public  HalloWelt {
    public static  main(String[] args) {
        System.out.("Hallo Welt")
    }

Programmierung

Legt für diesen Abschnitt ein Projekt Abschnitt2 an (siehe Abschnitt 0). Ihr arbeitet in einer einzigen main-Methode -- der Code für jede Aufgabe wird einfach ans Ende des bisherigen Codes angehängt, nicht ersetzt.

Aufgabe 1 -- Eigene Ausgabe

Gebt euren Namen und eure Lieblingsprogrammiersprache aus -- jeweils in einer eigenen Zeile.

Verwendet für jede Zeile einen eigenen Aufruf von System.out.println(...).

Aufgabe 2 -- print und println kombinieren

Ergänzt euren Code so, dass zusätzlich folgende Ausgabe erzeugt wird:

Name: Max Mustermann
Straße: Musterweg 1, PLZ Ort: 84034 Landshut

Überlegt genau, wo ihr print und wo ihr println braucht, damit der Zeilenumbruch an der richtigen Stelle passiert.

Die zweite Zeile besteht aus zwei Ausgaben, die direkt hintereinander in derselben Zeile stehen sollen.

Aufgabe 3 -- Fehler provozieren und verstehen

Sucht euch eine beliebige Zeile aus eurem bisherigen Code und entfernt vorübergehend ein Semikolon. Führt das Programm aus und lest die Fehlermeldung im Output-Fenster genau durch.

Macht dasselbe anschließend mit einer fehlenden schließenden Klammer }. Vergleicht beide Fehlermeldungen -- was ist unterschiedlich?

Wichtig: Macht beide Änderungen danach wieder rückgängig, damit euer Code für die nächste Aufgabe wieder fehlerfrei ist.

Ergänzt euren Code um mehrere println-Aufrufe, die ein kleines Haus aus Zeichen wie /, \, | und _ auf die Konsole zeichnen.

Achtet darauf, dass jede Zeile in eurem Code exakt so viele Leerzeichen enthält, wie ihr für die Ausgabe braucht -- Java entfernt keine Leerzeichen aus einem String.
