Vorbereitung

Vorbereitung

In diesem Kurs schreibt ihr euren Code die meiste Zeit direkt in die main-Methode -- Funktionen und Klassen lernt ihr erst gegen Ende kennen. Pro Abschnitt legt ihr in der Regel ein Projekt an und ergänzt darin nach und nach: Der Code für jede neue Aufgabe wird einfach an das Ende der bestehenden main-Methode angehängt, nicht ersetzt. Nur wenn eine Aufgabe ausdrücklich ein eigenständiges Projekt verlangt, legt ihr ein zusätzliches Projekt an. Welcher Fall gerade zutrifft, steht jeweils in der Aufgabenstellung.

Schritt für Schritt: Neues Projekt anlegen
  1. Öffnet Apache NetBeans.
  2. Menü Datei > Neues Projekt auswählen.
  3. Kategorie Java mit Ant wählen, danach Java-Anwendung.
  4. Als Projektname den Namen eintragen, der in der jeweiligen Aufgabe angegeben ist, und das Projekt anlegen.
  5. Im Projektbaum öffnet sich automatisch eine Datei mit einer main-Methode -- dort schreibt ihr im Laufe des Abschnitts euren Code hinein, Aufgabe für Aufgabe angehängt.

Klickt mit der rechten Maustaste auf eure Datei im Projektbaum und wählt Run File, oder drückt Umschalt + F6. Unten öffnet sich das Output-Fenster. Steht dort am Ende

BUILD SUCCESS

dann läuft eure Umgebung korrekt.

Prüft zuerst, ob rot unterstrichene Stellen im Code vorhanden sind -- fahrt mit der Maus darüber, NetBeans zeigt euch die Fehlermeldung an. Meldet euch, wenn ihr die Meldung nicht versteht.
