Information

Bisher stand euer gesamter Code in der main-Methode. Mit Funktionen (in Java auch Methoden genannt) könnt ihr Code in benannte, wiederverwendbare Bausteine auslagern, die ihr von überall aus aufrufen könnt -- auch mehrfach, ohne ihn erneut abzuschreiben. Fülle das Arbeitsblatt anhand des Informationstextes aus.

Eine eigene Methode definieren und aufrufen

Eine Methode steht neben der main-Methode in derselben Klasse. Sie hat einen Namen, über den sie von main aus aufgerufen werden kann.

public class Beispiel {

    static void begruessung() {
        System.out.println("Hallo!");
    }

    public static void main(String[] args) {
        begruessung();
    }
}

Beim Aufruf begruessung(); springt das Programm zur Methode begruessung, führt deren Code aus und kehrt danach genau an die Stelle zurück, an der sie aufgerufen wurde.

static hängt mit Klassen und Objekten zusammen, die ihr in diesem Kurs noch nicht im Detail behandelt. Für den Moment reicht es, sich zu merken: Jede Methode, die ihr direkt aus main heraus aufrufen wollt, braucht ebenfalls static davor -- genau wie main selbst. Im anschließenden Pong-Projekt lernt ihr, was dahinter genau steckt.

Parameter

Mit Parametern könnt ihr einer Methode Werte übergeben, die sie bei ihrer Ausführung verwendet. Beim Aufruf übergebt ihr passende Argumente -- die konkreten Werte für diese Parameter.

static void begruesse(String name) {
    System.out.println("Hallo, " + name + "!");
}

public static void main(String[] args) {
    begruesse("Nina");
    begruesse("Tom");
}

Der Parameter name gilt nur innerhalb der Methode begruesse. Bei jedem Aufruf könnt ihr ein anderes Argument übergeben, hier einmal "Nina" und einmal "Tom" -- die Methode selbst müsst ihr dafür nur einmal schreiben.

Ihr könnt eine Methode auch mit mehreren Parametern ausstatten, getrennt durch Kommas:

static void begruesse(String name, int alter) {
    System.out.println("Hallo " + name + ", du bist " + alter + " Jahre alt.");
}
Rückgabewerte

Bisher hatten unsere Methoden den Rückgabetyp void -- sie geben also nichts zurück, sondern führen nur Anweisungen aus. Mit einem anderen Rückgabetyp kann eine Methode stattdessen einen Wert berechnen und an die aufrufende Stelle zurückgeben.

static int quadrat(int zahl) {
    return zahl * zahl;
}

public static void main(String[] args) {
    int ergebnis = quadrat(5);
    System.out.println(ergebnis);
}

Statt void steht hier int vor dem Methodennamen -- das legt fest, welchen Datentyp der Rückgabewert hat. Mit return wird dieser Wert an die aufrufende Stelle zurückgegeben, hier direkt in die Variable ergebnis. Eine Methode mit Rückgabetyp muss auf jedem möglichen Ausführungspfad ein return erreichen -- sonst meldet der Compiler einen Fehler.

Scope (Gültigkeitsbereich)

Variablen, die ihr innerhalb einer Methode deklariert -- auch Parameter -- nennt man lokale Variablen. Sie existieren nur innerhalb dieser Methode und sind außerhalb davon unbekannt.

static void zeigeZahl() {
    int zahl = 42;
    System.out.println(zahl);
}

public static void main(String[] args) {
    zeigeZahl();
    System.out.println(zahl); // Fehler: zahl ist hier nicht bekannt
}

Die Variable zahl aus zeigeZahl existiert nur, während diese Methode läuft. Sobald die Methode beendet ist, ist zahl wieder verschwunden -- deshalb schlägt der Zugriff darauf in main fehl. Umgekehrt kann auch main nicht auf lokale Variablen anderer Methoden zugreifen und andere Methoden nicht auf lokale Variablen von main. Der einzige Weg, Werte zwischen Methoden auszutauschen, sind Parameter und Rückgabewerte.

Programmierung

Legt für diesen Abschnitt ein Projekt Abschnitt9 an (siehe Abschnitt 0). Definiert eure Methoden für jede Aufgabe zusätzlich neben main in derselben Datei, und ruft sie dann aus main heraus auf -- der Aufruf in main wird wie gewohnt einfach ans Ende des bisherigen Codes angehängt.

Aufgabe 1 -- Methode ohne Parameter

Schreibt eine Methode trennlinie ohne Parameter und ohne Rückgabewert, die eine Zeile aus zehn Bindestrichen ausgibt. Ruft sie in main mehrfach an unterschiedlichen Stellen auf.

static void trennlinie() { -- ohne Rückgabewert bleibt es bei void, ohne Parameter bleiben die Klammern leer.

Aufgabe 2 -- Methode mit Parameter

Schreibt eine Methode begruesse, die einen String name als Parameter entgegennimmt und "Hallo, " + name + "!" ausgibt. Ruft sie in main mit mindestens drei verschiedenen Namen auf.

In den runden Klammern des Methodenkopfs, mit Datentyp davor: static void begruesse(String name) {.

Aufgabe 3 -- Methode mit Rückgabewert

Schreibt eine Methode verdoppeln, die einen int-Parameter entgegennimmt und den doppelten Wert zurückgibt. Ruft sie in main mit mehreren Zahlen auf, speichert das jeweilige Ergebnis in einer Variable und gebt es aus.

Statt void steht jetzt int vor dem Methodennamen, und im Methodenrumpf braucht ihr eine return-Anweisung mit dem berechneten Wert.

Aufgabe 4 -- Mehrere Parameter

Schreibt eine Methode rechteckflaeche, die breite und hoehe (beide double) als Parameter entgegennimmt und die Fläche des Rechtecks zurückgibt. Ruft sie in main mit mindestens zwei verschiedenen Wertepaaren auf und gebt jeweils das Ergebnis aus.

Durch ein Komma, jeweils mit eigenem Datentyp: static double rechteckflaeche(double breite, double hoehe) {.

Aufgabe 5 -- Scope verstehen

Nehmt eine eurer bisherigen Methoden mit einer lokalen Variable und versucht testweise, in main direkt auf diese Variable zuzugreifen (zum Beispiel sie dort auszugeben). Lest die Fehlermeldung und löscht den Testzugriff danach wieder.

Schreibt eine Methode ggt, die zwei int-Parameter entgegennimmt und ihren größten gemeinsamen Teiler zurückgibt -- die größte Zahl, durch die beide Eingabewerte ohne Rest teilbar sind. Ruft die Methode in main mit mehreren Zahlenpaaren auf, darunter mindestens ein Paar, bei dem der ggT 1 ist.

Eine Möglichkeit ist, mit einer Schleife alle Zahlen bis zum kleineren der beiden Werte durchzugehen und zu prüfen, welche davon Teiler beider Zahlen sind. Es gibt auch schnellere Verfahren -- recherchiert dazu gerne den Begriff "euklidischer Algorithmus", falls ihr eine elegantere Lösung sucht.
