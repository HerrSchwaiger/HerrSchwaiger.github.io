Die while-Schleife

Eine while-Schleife prüft vor jedem Durchlauf eine Bedingung. Ist sie true, wird der Codeblock ausgeführt, danach wird erneut geprüft -- so lange, bis die Bedingung false ist.

int i = 0;
while (i < 5) {
    System.out.println(i);
    i = i + 1;
}

Im Unterschied zur for-Schleife stehen Zählvariable, Bedingung und Änderung hier nicht kompakt in einer Zeile, sondern verteilt: Die Zählvariable wird vor der Schleife angelegt, die Änderung steht am Ende des Codeblocks. Eine while-Schleife braucht nicht einmal zwingend eine Zählvariable -- die Bedingung kann auch von etwas ganz anderem abhängen, zum Beispiel einer Nutzereingabe.

Vergesst ihr die Zeile i = i + 1;, bleibt i immer 0 und die Bedingung i < 5 immer true -- die Schleife läuft dann endlos weiter und euer Programm reagiert nicht mehr. Bei einer while-Schleife passiert das leichter als bei einer for-Schleife, weil die Änderung der Zählvariable nicht direkt neben der Bedingung im Schleifenkopf steht und deshalb leichter vergessen wird.

Die do-while-Schleife

Eine do-while-Schleife prüft die Bedingung erst nach dem ersten Durchlauf -- der Codeblock wird also immer mindestens einmal ausgeführt, egal ob die Bedingung überhaupt zutrifft.

int i = 0;
do {
    System.out.println(i);
    i = i + 1;
} while (i < 5);

Der Unterschied zur while-Schleife fällt nur auf, wenn die Bedingung von Anfang an false ist: Eine while-Schleife würde dann gar nicht laufen, eine do-while-Schleife aber genau einmal. Beachtet außerdem die Syntax: Bei do-while steht nach der Bedingung am Ende noch ein Semikolon.

Programmierung

Legt für diesen Abschnitt ein Projekt Abschnitt8 an (siehe Abschnitt 0). Ihr arbeitet in einer einzigen main-Methode -- der Code für jede Aufgabe wird einfach ans Ende des bisherigen Codes angehängt, nicht ersetzt.

Aufgabe 1 -- Countdown mit while

Deklariert eine int-Variable zaehler mit dem Wert 10. Gebt mit einer while-Schleife rückwärts von 10 bis 1 alle Zahlen aus und zum Schluss "Start!".

Da rückwärts gezählt wird, müsst ihr den Zähler in jedem Durchlauf verringern, nicht erhöhen.

Aufgabe 2 -- Mindestens einmal ausführen

Deklariert eine int-Variable versuch mit dem Wert 0. Schreibt eine do-while-Schleife, die "Versuch Nummer " + versuch ausgibt und versuch erhöht, solange versuch kleiner als 3 ist. Ändert testweise den Startwert auf 5 und beobachtet, was trotzdem passiert.

Bei do-while wird die Bedingung erst nach dem ersten Durchlauf geprüft -- der Codeblock läuft deshalb immer mindestens einmal, egal was die Bedingung sagt.

Aufgabe 3 -- Quersumme berechnen

Deklariert eine int-Variable zahl mit einem mehrstelligen Wert, zum Beispiel 4827. Berechnet mit einer while-Schleife die Quersumme -- also die Summe aller einzelnen Ziffern -- und gebt sie aus. Für 4827 wäre das Ergebnis 4+8+2+7 = 21.

Der Rest einer Division durch 10 (zahl % 10) liefert euch die letzte Ziffer. Überlegt euch danach, wie ihr diese Ziffer "entfernt", um an die nächste heranzukommen, und wann die Schleife enden soll.

Aufgabe 4 -- Zahl umkehren

Deklariert eine int-Variable zahl mit einem mehrstelligen Wert, zum Beispiel 4827. Berechnet mit einer while-Schleife die Zahl mit umgekehrter Ziffernreihenfolge und gebt sie aus. Für 4827 wäre das Ergebnis 7284.

Das Vorgehen ähnelt Aufgabe 3: Holt euch mit % 10 die letzte Ziffer, hängt sie aber diesmal an eine zweite Variable an, statt sie nur aufzusummieren. Überlegt, wie "anhängen" bei Zahlen rechnerisch funktioniert -- multiplizieren mit 10 könnte helfen.

Die Collatz-Folge funktioniert so: Startet mit einer beliebigen positiven ganzen Zahl. Ist sie gerade, teilt sie durch 2. Ist sie ungerade, berechnet 3 * zahl + 1. Wiederholt das mit dem jeweils neuen Wert, bis ihr bei 1 ankommt. Deklariert eine int-Variable zahl mit einem Startwert eurer Wahl, führt die Collatz-Folge mit einer Schleife durch, gebt jeden Zwischenwert aus und zählt am Ende, wie viele Schritte bis zur 1 nötig waren. Testet euren Code mit mindestens zwei verschiedenen Startwerten.

Überlegt, ob ihr vorher wisst, wie viele Schritte nötig sind, bis die Zahl 1 erreicht wird -- das entscheidet, welche der beiden in diesem Abschnitt gelernten Schleifenarten besser passt.
