Operatoren

Information

Mit Operatoren könnt ihr aus Werten und Variablen neue Werte berechnen -- rechnen, vergleichen und logisch verknüpfen. In diesem Abschnitt lernt ihr die drei wichtigsten Gruppen kennen. Fülle das Arbeitsblatt anhand des Informationstextes aus.

Arithmetische Operatoren

Diese Operatoren kennt ihr größtenteils schon aus dem Matheunterricht:

Operator Bedeutung Beispiel
+Addition5 + 2 ergibt 7
-Subtraktion5 - 2 ergibt 3
*Multiplikation5 * 2 ergibt 10
/Division5 / 2 ergibt 2 bei zwei int-Werten
%Modulo (Rest der Division)5 % 2 ergibt 1

Wenn beide Operanden vom Typ int sind, führt Java eine Ganzzahldivision durch: Das Ergebnis wird auf eine ganze Zahl abgeschnitten, die Nachkommastelle geht verloren. Ist mindestens einer der beiden Werte ein double, wird auch das Ergebnis ein double, zum Beispiel ergibt 5.0 / 2 den Wert 2.5.

Vergleichsoperatoren

Vergleichsoperatoren vergleichen zwei Werte miteinander und liefern immer ein Ergebnis vom Typ boolean -- also true oder false.

Operator Bedeutung Beispiel
==gleich5 == 5 ergibt true
!=ungleich5 != 3 ergibt true
>größer als5 > 3 ergibt true
<kleiner als5 < 3 ergibt false
>=größer oder gleich5 >= 5 ergibt true
<=kleiner oder gleich5 <= 3 ergibt false

Fahrt mit der Maus über die unterstrichenen Stellen im folgenden Code:

int alter = 16;
boolean istVolljaehrig = alter >= 18;
Logische Operatoren

Logische Operatoren verknüpfen mehrere boolean-Werte miteinander:

Operator Bedeutung Ergebnis ist true, wenn ...
&&UNDbeide Seiten true sind
||ODERmindestens eine Seite true ist
!NICHTder Wert dahinter false ist (kehrt ihn um)
 
boolean hatTicket = true;
boolean istPuenktlich = false;
boolean darfEinsteigen = hatTicket && istPuenktlich;

darfEinsteigen ist hier false, weil istPuenktlich false ist -- bei && müssen beide Seiten true sein.

Operatorrangfolge

Wie in der Mathematik gilt auch in Java "Punkt vor Strich": *, / und % werden vor + und - ausgewertet. Klammern könnt ihr wie gewohnt verwenden, um die Reihenfolge zu erzwingen.

int ergebnis1 = 2 + 3 * 4;
int ergebnis2 = (2 + 3) * 4;

ergebnis1 ist 14 (zuerst 3 * 4, dann + 2), ergebnis2 ist 20 (zuerst die Klammer, dann * 4). Vergleichsoperatoren werden immer erst nach den arithmetischen Operatoren ausgewertet, logische Operatoren erst nach den Vergleichsoperatoren.

Kurzes Video mit mehreren durchgerechneten Beispielen zur Reihenfolge von Operatoren.

Programmierung

Legt für diesen Abschnitt ein Projekt Abschnitt5 an. Ihr arbeitet in einer einzigen main-Methode -- der Code für jede Aufgabe wird einfach ans Ende des bisherigen Codes angehängt, nicht ersetzt.

Aufgabe 1 -- Grundrechenarten

Deklariert zwei int-Variablen a = 17 und b = 5. Berechnet und gebt aus: Summe, Differenz, Produkt, Ergebnis der Division und Rest der Division.

Ihr könnt die Berechnung direkt in System.out.println(...) schreiben, zum Beispiel System.out.println(a + b);, oder das Ergebnis vorher in einer eigenen Variable speichern.

Aufgabe 2 -- Gerade oder ungerade?

Deklariert eine int-Variable zahl mit einem selbst gewählten Wert. Berechnet mit dem Modulo-Operator eine boolean-Variable istGerade, die genau dann true ist, wenn zahl gerade ist, und gebt sie aus.

Eine Zahl ist gerade, wenn der Rest bei Division durch 2 gleich 0 ist.

Aufgabe 3 -- Logische Verknüpfung

Deklariert zwei boolean-Variablen hatFuehrerschein und istVolljaehrig mit selbst gewählten Werten. Berechnet eine Variable darfAutoFahren, die nur dann true ist, wenn beide Bedingungen erfüllt sind, und gebt sie aus. Ändert anschließend die Werte einmal so ab, dass sich das Ergebnis ändert, und testet erneut.

"Beide Bedingungen müssen erfüllt sein" ist eine UND-Verknüpfung.

Aufgabe 4 -- Rangfolge vorhersagen

Notiert euch zuerst auf Papier, welches Ergebnis ihr für folgende Ausdrücke erwartet. Schreibt die Ausdrücke danach in euer Projekt, gebt sie aus und vergleicht mit eurer Vorhersage:

10 - 2 * 3
(10 - 2) * 3
10 > 5 && 3 < 1
10 > 5 || 3 < 1

Ein Jahr ist ein Schaltjahr, wenn es durch 4 teilbar ist, aber nicht durch 100 -- außer es ist auch durch 400 teilbar, dann ist es trotzdem ein Schaltjahr. Deklariert eine int-Variable jahr und berechnet mit Modulo- und logischen Operatoren eine boolean-Variable istSchaltjahr, die das korrekt abbildet. Testet euren Code mit den Jahren 2000, 1900 und 2024.

Formuliert die Regel zunächst in Worten als drei einzelne Teilbedingungen (teilbar durch 4, teilbar durch 100, teilbar durch 400) und überlegt dann, mit welchen logischen Operatoren ihr diese drei Teilbedingungen zu einer Gesamtbedingung verknüpfen müsst.
