Stell dir vor, du willst sechs Lottozahlen in deinem Programm speichern. Du könntest sechs einzelne Variablen anlegen. Das funktioniert – aber es ist umständlich. Und was ist, wenn es 100 Zahlen wären? Die elegante Lösung heißt **Array**. Ein Array fasst mehrere Werte **desselben Datentyps** unter einem einzigen Namen zusammen.

## Arrays erstellen

Die allgemeine Syntax lautet:

```java
typ[] arrayName = new typ[Gesamtgroesse];
```

Für unsere Lottozahlen sieht das konkret so aus:

```java
int[] lottozahlen = new int[6];
```

Damit haben wir ein Array mit **6 Plätzen** (Indizes 0 bis 5) für ganze Zahlen angelegt. Die Plätze sind zunächst leer (bzw. mit dem Standardwert `0` vorbelegt).

### Elemente hinzufügen

Jedes Element hat eine **Indexnummer**, beginnend bei `0`. Das erste Element hat Index 0, das letzte Index `n-1` (bei Größe n).

```java
int[] lottozahlen = new int[6];

lottozahlen[0] = 2;
lottozahlen[1] = 7;
lottozahlen[2] = 11;
lottozahlen[3] = 30;
lottozahlen[4] = 41;
lottozahlen[5] = 42;
```

| Index | Zugriff          | Wert |
|-------|------------------|------|
| 0     | lottozahlen[0]   | 2    |
| 1     | lottozahlen[1]   | 7    |
| 2     | lottozahlen[2]   | 11   |
| 3     | lottozahlen[3]   | 30   |
| 4     | lottozahlen[4]   | 41   |
| 5     | lottozahlen[5]   | 42   |

### Kurzform: Initialisierungsliste

Wenn die Werte beim Erstellen bereits bekannt sind, geht es noch kürzer:

```java
int[] lottozahlen = {2, 7, 11, 30, 41, 42};
```

Java erkennt die Größe automatisch aus der Anzahl der Elemente.

## Auf Elemente zugreifen

Einzelne Elemente werden über ihren Index gelesen:

```java
System.out.println(lottozahlen[3]); // Ausgabe: 30
System.out.println(lottozahlen[5]); // Ausgabe: 42

int summe = lottozahlen[0] + lottozahlen[1]; // 9
```


## ArrayIndexOutOfBoundsException

Ein häufiger Fehler: Man greift auf einen Index zu, der **außerhalb des gültigen Bereichs** liegt.

Bei einem Array der Größe 6 sind nur die Indizes `0` bis `5` gültig. Index `6` existiert nicht:

```java
lottozahlen[6] = 8; // Laufzeitfehler: ArrayIndexOutOfBoundsException
```

Das Programm bricht dann mit einer Fehlermeldung ab. Diese Exception taucht besonders häufig auf, wenn man Arrays in Schleifen durchläuft – dazu gleich mehr.

## Arrays und Schleifen

Arrays und Schleifen gehören zusammen. Betrachte dieses String-Array:

```java
String[] filmklassiker = {
    "Terminator",
    "Casablanca",
    "2001: Odyssee im Weltraum",
    "Der Pate",
    "Inception",
    "Pulp Fiction",
    "Fight Club",
    "Schindlers Liste"
};
```

Alle Elemente einzeln mit `System.out.println` auszugeben wäre schlechter Stil (*Don't repeat yourself!*). Die saubere Lösung ist eine **for-Schleife**:

```java
for (int i = 0; i < filmklassiker.length; i++) {
    System.out.println(filmklassiker[i]);
}
```

- `i` startet bei `0` (erster Index)
- `filmklassiker.length` gibt die Länge des Arrays zurück (hier: 8)
- Die Bedingung `i < filmklassiker.length` stellt sicher, dass kein Index außerhalb des Bereichs verwendet wird → keine `ArrayIndexOutOfBoundsException`

> 💡 **Tipp:** Nutze immer `array.length` als Schleifengrenze – nie einen hartcodierten Zahlenwert. So bleibt der Code korrekt, auch wenn das Array später größer oder kleiner wird.

## Mehrdimensionale Arrays

Bisher hatten alle unsere Arrays eine Dimension – wie eine Liste. Für komplexere Datenstrukturen (z. B. eine Tabelle oder ein Spielfeld) brauchen wir **mehrdimensionale Arrays**.

> Ein zweidimensionales Array ist ein Array, dessen Elemente selbst wieder Arrays sind.

Man kann es sich wie ein Raster mit Zeilen und Spalten vorstellen.

### Erstellen

```java
int[][] tabelle = new int[4][5];
```

Hier entstehen 4 Zeilen mit je 5 Spalten. Insgesamt also 20 Speicherplätze.

### Elemente zuweisen

```java
tabelle[0][1] = 100;
tabelle[1][4] = 150;
```

- `tabelle[0][1]` → Zeile 0, Spalte 1 → Wert: 100
- `tabelle[1][4]` → Zeile 1, Spalte 4 → Wert: 150
- Alle anderen Felder haben den Standardwert `0`

### Mit Initialisierungsliste (unterschiedliche Zeilenlängen)

Subarrays können auch unterschiedlich lang sein:

```java
int[][] ungleich = { {2, 4, 1, 34}, {1}, {9, 10, 14} };

System.out.println(ungleich[0].length); // 4
System.out.println(ungleich[1].length); // 1
System.out.println(ungleich[2].length); // 3
```

### 2D-Array mit Schleife durchlaufen

Um alle Elemente eines 2D-Arrays auszugeben, verwendet man eine **verschachtelte for-Schleife**:

```java
for (int i = 0; i < tabelle.length; i++) {
    for (int j = 0; j < tabelle[i].length; j++) {
        System.out.print(tabelle[i][j] + "\t");
    }
    System.out.println();
}
```

## Zusammenfassung

| Konzept                        | Kernaussage                                                    |
|-------------------------------|----------------------------------------------------------------|
| Array erstellen               | `typ[] name = new typ[größe];`                                |
| Initialisierungsliste          | `typ[] name = {wert1, wert2, ...};`                           |
| Index                         | Beginnt bei `0`, endet bei `länge - 1`                        |
| Größe abfragen                | `name.length`                                                  |
| Schleife über Array           | `for (int i = 0; i < name.length; i++)`                      |
| Fehler vermeiden              | Immer `length` als Schleifengrenze nutzen                      |
| 2D-Array                      | `typ[][] name = new typ[zeilen][spalten];`                    |
