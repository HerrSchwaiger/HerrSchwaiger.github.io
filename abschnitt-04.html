Information

Jede Variable hat einen festen Datentyp, der bestimmt, welche Art von Wert sie speichern kann und wie viel Platz dafür im Speicher reserviert wird. In diesem Abschnitt lernt ihr die wichtigsten Datentypen in Java kennen. Fülle das Arbeitsblatt anhand des Informationstextes aus.

Primitive Datentypen

Java unterscheidet zwischen wenigen fest eingebauten, sogenannten primitiven Datentypen. Die wichtigsten für den Einstieg sind:

Datentyp Speichert Beispielwert
int ganze Zahlen 42, -7
double Kommazahlen 3.14, -0.5
boolean Wahrheitswerte true, false
char ein einzelnes Zeichen 'A', '7'

Fahrt mit der Maus über die unterstrichenen Stellen im folgenden Code:

int punkte = 100;
double preis = 4.99;
boolean angemeldet = true;
char note = 'A';

Achtet dabei genau auf die Anführungszeichen: Ein char-Wert steht in einfachen Anführungszeichen ('A') und darf nur ein einziges Zeichen enthalten.

String -- ein Sonderfall

String ist kein primitiver Datentyp, sondern speichert eine ganze Zeichenkette aus beliebig vielen Zeichen. Ihr habt String schon in den vorherigen Abschnitten benutzt. Der Unterschied zu char: String-Werte stehen in doppelten Anführungszeichen und können auch leer sein oder mehrere Zeichen enthalten.

char
char zeichen = 'J';

Genau ein Zeichen, einfache Anführungszeichen.

String
String wort = "Java";

Beliebig viele Zeichen, doppelte Anführungszeichen.

String ist in Java streng genommen eine Klasse, kein primitiver Datentyp -- deshalb die Großschreibung, so wie bei allen Klassennamen. Für den Einstieg reicht es aber, String einfach wie einen weiteren Datentyp zu benutzen. Mehr zu Klassen lernt ihr später im Kurs.

Typumwandlung (Casting)

Manchmal müsst ihr einen Wert von einem Datentyp in einen anderen umwandeln. Das nennt man Casting. Bei manchen Umwandlungen kann Java das automatisch erledigen, bei anderen müsst ihr es explizit anfordern.

int ganzzahl = 7;
double kommazahl = ganzzahl;

Diese Richtung -- von int nach double -- funktioniert automatisch, weil dabei keine Information verloren geht: Jede ganze Zahl lässt sich verlustfrei als Kommazahl darstellen.

double preis = 4.99;
int ganzzahl = (int) preis;

Umgekehrt -- von double nach int -- geht die Kommastelle verloren, deshalb müsst ihr das mit (int) vor dem Wert explizit anfordern. Java rundet dabei nicht, sondern schneidet die Nachkommastellen einfach ab: Aus 4.99 wird 4, nicht 5.

Kurzes Video, das Casting zwischen int und double an mehreren Beispielen zeigt.

Übung: Datentyp Zuordnung

Zieht jeden Wert in die Zone des passenden Datentyps. Passt ein Wert zu keinem der fünf Datentypen, weil er zum Beispiel falsch geschrieben ist, gehört er in die Zone Error.

Frage 1 von 13
42

Zieht den Wert in die passende Zone.

Alle Werte einsortiert.

    Programmierung

    Legt für diesen Abschnitt ein Projekt Abschnitt4 an (siehe Abschnitt 0). Ihr arbeitet in einer einzigen main-Methode -- der Code für jede Aufgabe wird einfach ans Ende des bisherigen Codes angehängt, nicht ersetzt.

    Aufgabe 1 -- Alle Datentypen einmal verwenden

    Deklariert je eine Variable vom Typ int, double, boolean und char mit selbst gewählten, sinnvollen Werten und gebt alle vier aus.

    Einfache Anführungszeichen und genau ein Zeichen, zum Beispiel char note = 'B';.

    Aufgabe 2 -- char und String unterscheiden

    Deklariert eine char-Variable mit eurem ersten Buchstaben und eine String-Variable mit eurem vollständigen Vornamen. Gebt beide aus.

    Doppelte Anführungszeichen, zum Beispiel String vorname = "Nina";.

    Aufgabe 3 -- Casting ausprobieren

    Deklariert eine double-Variable mit dem Wert 9.87. Wandelt sie per Casting in eine int-Variable um und gebt beide Werte aus. Überprüft, ob das Ergebnis eurer Erwartung entspricht.

    Den Zieltyp in runden Klammern direkt vor den Wert schreiben, zum Beispiel (int) 9.87.

    Aufgabe 4 -- Fehlerhafte Typen erkennen

    Versucht nacheinander folgende Zeilen, notiert euch die jeweilige Fehlermeldung und löscht die Zeile danach wieder, bevor ihr die nächste ausprobiert:

    char zeichen = "AB";
int zahl = 4.5;
boolean wert = 1;

    Überlegt euch jeweils, warum Java diesen Code ablehnt.

    Ihr habt gesehen, dass (int) beim Casting die Nachkommastellen einfach abschneidet, statt mathematisch zu runden. Findet einen Weg, eine double-Variable wie 4.7 so in einen int-Wert umzuwandeln, dass korrekt gerundet wird (also zu 5, nicht zu 4). Testet euren Ansatz auch mit einem Wert wie 4.3, der auf 4 abgerundet werden muss.

    Überlegt, was mit dem Wert passieren müsste, bevor ihr ihn abschneidet, damit aus einem Abschneiden ein korrektes Runden wird. Ein Blick in die Java-Dokumentation zur Klasse Math könnte helfen.
