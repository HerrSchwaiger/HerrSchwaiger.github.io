Information

Bisher konnte jede Variable genau einen Wert speichern. Mit einem Array (auf Deutsch manchmal Feld genannt) könnt ihr mehrere Werte desselben Datentyps unter einem einzigen Namen speichern und über eine Position ansprechen. Fülle das Arbeitsblatt anhand des Informationstextes aus.

Ein Array anlegen

Es gibt zwei gängige Wege, ein Array zu erstellen:

int[] zahlen = new int[5];
int[] noten = {1, 3, 2, 2, 4};

Die eckigen Klammern [] hinter dem Datentyp zeigen, dass es sich um ein Array handelt. Bei der ersten Schreibweise legt ihr nur die Größe fest, alle Werte sind zunächst 0. Bei der zweiten Schreibweise gebt ihr die Werte direkt mit an -- die Größe ergibt sich automatisch aus der Anzahl der Werte.

Zugriff über den Index

Auf einzelne Werte greift ihr über ihre Position zu, den Index. Wichtig: In Java beginnt die Zählung bei 0, nicht bei 1.

int[] noten = {1, 3, 2, 2, 4};
System.out.println(noten[0]);
System.out.println(noten[2]);
noten[1] = 5;
System.out.println(noten[1]);

noten[0] ist die erste Note (1), noten[2] die dritte Note (2). Nach der Zuweisung noten[1] = 5; ist die zweite Note auf 5 geändert.

Greift ihr auf einen Index zu, den es nicht gibt -- zum Beispiel noten[5] bei einem Array mit nur 5 Werten (gültige Indizes 0 bis 4) -- bricht das Programm zur Laufzeit mit einer ArrayIndexOutOfBoundsException ab. Das ist einer der häufigsten Anfängerfehler bei Arrays, weil der letzte gültige Index immer um 1 kleiner ist als die Array-Länge.

Die Länge eines Arrays

Mit .length (ohne runde Klammern, anders als bei Methoden) erfahrt ihr, wie viele Werte ein Array enthält:

int[] noten = {1, 3, 2, 2, 4};
System.out.println(noten.length);

Diese Ausgabe ist 5. Der letzte gültige Index ist demnach noten.length - 1, hier also 4.

Arrays mit einer Schleife durchlaufen

Meist wollt ihr nicht auf einen einzelnen Wert zugreifen, sondern alle Werte eines Arrays der Reihe nach verarbeiten. Dafür eignet sich eine for-Schleife, die über den Index läuft:

int[] noten = {1, 3, 2, 2, 4};
for (int i = 0; i < noten.length; i = i + 1) {
    System.out.println(noten[i]);
}

Die Schleife läuft von 0 bis noten.length - 1 -- also genau über alle gültigen Indizes des Arrays, unabhängig davon, wie lang das Array tatsächlich ist. Deshalb funktioniert dieser Code auch, wenn sich die Länge des Arrays später ändert.

Wenn ihr den Index selbst gar nicht braucht, sondern nur jeden Wert einzeln, gibt es in Java eine kompaktere Schreibweise, die sogenannte for-each-Schleife:

for (int note : noten) {
    System.out.println(note);
}

Das bedeutet sinngemäß "für jeden Wert note in noten". Diese Schreibweise ist kürzer, funktioniert aber nur, wenn ihr wirklich nur lesend auf jeden Wert zugreifen wollt -- den Index selbst kennt ihr dabei nicht.

Überlegt euch ein Verfahren, das wiederholt benachbarte Elemente vergleicht und vertauscht, wenn sie in der falschen Reihenfolge stehen -- und wie oft ihr das über das ganze Array wiederholen müsst, damit am Ende garantiert alles sortiert ist. Zwei ineinander verschachtelte Schleifen könnten dabei helfen. Der Fachbegriff für ein solches Verfahren lautet "Bubble Sort", falls ihr dazu recherchieren wollt.
