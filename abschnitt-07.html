Information

Wollt ihr einen Codeblock mehrfach ausführen, ohne ihn mehrfach abzuschreiben, braucht ihr eine Schleife. In diesem Abschnitt lernt ihr die for-Schleife kennen, die sich besonders eignet, wenn ihr schon vorher wisst, wie oft ein Codeblock durchlaufen werden soll. Fülle das Arbeitsblatt anhand des Informationstextes aus.

Die for-Schleife

Eine for-Schleife fasst drei Dinge in einer einzigen Zeile zusammen: eine Zählvariable, eine Bedingung und eine Änderung der Zählvariable nach jedem Durchlauf.

for (int i = 0; i < 5; i = i + 1) {
    System.out.println(i);
}

Diese Schleife gibt die Zahlen 0, 1, 2, 3, 4 aus. Sobald i gleich 5 ist, ist die Bedingung i < 5 nicht mehr erfüllt und die Schleife endet.

Statt i = i + 1 schreibt man in Java meist kürzer i++ -- beides bedeutet genau dasselbe. Ihr werdet i++ in fremdem Code sehr häufig sehen, könnt in euren eigenen Lösungen aber gerne bei der ausführlichen Schreibweise bleiben, wenn euch das klarer ist.

Verschachtelte for-Schleifen

Genau wie if-Anweisungen lassen sich auch Schleifen ineinander verschachteln. Bei jedem Durchlauf der äußeren Schleife läuft die innere Schleife dann komplett durch.

for (int zeile = 1; zeile <= 3; zeile = zeile + 1) {
    for (int spalte = 1; spalte <= 3; spalte = spalte + 1) {
        System.out.println(zeile + " * " + spalte + " = " + (zeile * spalte));
    }
}

Für jeden Wert von zeile (1, 2, 3) läuft die innere Schleife komplett mit allen Werten von spalte (1, 2, 3) durch -- insgesamt also 3 mal 3, also 9 Ausgaben.

Schleifen vorzeitig steuern: break und continue

Mit break könnt ihr eine Schleife sofort komplett verlassen, mit continue nur den aktuellen Durchlauf überspringen und direkt zur Bedingung des nächsten Durchlaufs springen.

for (int i = 0; i < 10; i = i + 1) {
    if (i == 5) {
        break;
    }
    System.out.println(i);
}

Diese Schleife gibt nur die Zahlen 0 bis 4 aus -- sobald i gleich 5 ist, wird die Schleife komplett verlassen.

for (int i = 0; i < 5; i = i + 1) {
    if (i == 2) {
        continue;
    }
    System.out.println(i);
}

Diese Schleife gibt 0, 1, 3, 4 aus -- bei i == 2 wird nur die Ausgabe für diesen einen Durchlauf übersprungen, die Schleife läuft aber weiter.

Klickt auf "Start"/"Weiter", um die Schleife Schritt für Schritt auszuführen. Der dunkelblaue Zeiger (j) ist die mittlere Schleife und muss einmal komplett herum, bevor sich der hellblaue Zeiger (i) einen Schritt weiterbewegt. Genau wie bei einer Uhr der Minutenzeiger einmal ganz herum muss, bevor der Stundenzeiger weiterspringt.

for (int i = 0; i < 3; i++) {
    for (int j = 0; j < 4; j++) {
        System.out.println("i = " + i + ", j = " + j);
    }
}
for (int i = 0; i < 3; i++) {
    for (int j = 0; j < 4; j++) {
        for (int k = 0; k < 2; k++) {
            System.out.println("i = " + i + ", j = " + j + ", k = " + k);

    }

Programmierung

Legt für diesen Abschnitt ein Projekt Abschnitt7 an (siehe Abschnitt 0). Ihr arbeitet in einer einzigen main-Methode -- der Code für jede Aufgabe wird einfach ans Ende des bisherigen Codes angehängt, nicht ersetzt.

Aufgabe 1 -- Zählen mit for

Gebt mit einer for-Schleife die Zahlen von 1 bis 10 aus, jede in einer eigenen Zeile.

Da ihr bei 1 statt bei 0 beginnen sollt, startet die Zählvariable mit int i = 1, und die Bedingung lautet i <= 10.

Aufgabe 2 -- Summe und Produkt

Berechnet mit einer Schleife sowohl die Summe als auch das Produkt aller ganzen Zahlen von 1 bis 10 und gebt beide Ergebnisse aus.

Die Summe startet sinnvollerweise bei 0, das Produkt aber bei 1 -- würdet ihr das Produkt bei 0 starten, wäre das Endergebnis immer 0.

Aufgabe 3 -- break und continue

Schreibt eine for-Schleife, die die Zahlen von 1 bis 20 durchgeht. Überspringt mit continue alle Zahlen, die durch 3 teilbar sind, und brecht die Schleife mit break komplett ab, sobald ihr bei 15 angekommen seid. Gebt alle anderen Zahlen aus.

Prüft zuerst die break-Bedingung, danach die continue-Bedingung -- beide als eigene if-Anweisung direkt am Anfang der Schleife.

Aufgabe 4 -- Einmaleins-Tabelle

Gebt mit zwei verschachtelten for-Schleifen das kleine Einmaleins für die Zahlen 1 bis 5 aus -- also alle Ergebnisse von 1*1 bis 5*5, jedes in einer eigenen Zeile im Format zeile * spalte = ergebnis.

Zwei ineinander verschachtelte for-Schleifen, ganz wie im Beispiel im Informationstext -- eine für die Zeile, eine für die Spalte.

Aufgabe 5 -- Ist die Zahl eine Primzahl?

Eine Primzahl ist eine ganze Zahl größer als 1, die nur durch 1 und sich selbst ohne Rest teilbar ist. Deklariert eine int-Variable zahl und prüft mit einer Schleife, ob sie eine Primzahl ist. Gebt "Primzahl" oder "keine Primzahl" aus. Testet euren Code mit mehreren Zahlen, darunter mindestens eine Primzahl und eine, die keine ist.

Überlegt, durch welche Zahlen ihr zahl testweise teilen müsstet, um einen Teiler zu finden, der zeigt, dass sie keine Primzahl ist -- und wie ihr in einer Schleife nach so einem Teiler sucht.

Eine Zahl heißt vollkommen (perfekt), wenn die Summe all ihrer echten Teiler (also aller Teiler außer der Zahl selbst) genau der Zahl entspricht. Die 6 ist zum Beispiel vollkommen, weil ihre echten Teiler 1, 2 und 3 zusammen 6 ergeben. Schreibt Code, der mit verschachtelten for-Schleifen alle vollkommenen Zahlen zwischen 1 und 1000 findet und ausgibt.

Überlegt euch zunächst, wie ihr für eine einzelne, feste Zahl die Summe ihrer echten Teiler berechnet -- das braucht bereits eine eigene Schleife. Danach überlegt, wie ihr diese Berechnung für jede Zahl von 1 bis 1000 wiederholt.
