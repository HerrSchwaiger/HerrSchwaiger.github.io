Information

Bisher lief euer Code immer Zeile für Zeile von oben nach unten durch. Mit Bedingungen könnt ihr steuern, dass bestimmte Codeteile nur unter bestimmten Voraussetzungen ausgeführt werden. Fülle das Arbeitsblatt anhand des Informationstextes aus.

Die if-Anweisung

Eine if-Anweisung prüft eine Bedingung, die einen boolean-Wert ergibt. Ist die Bedingung true, wird der Codeblock danach ausgeführt -- sonst nicht.

int alter = 16;
if (alter >= 18) {
    System.out.println("Volljährig");
}

Die Bedingung steht in runden Klammern, der auszuführende Code in geschweiften Klammern. Ist alter hier kleiner als 18, wird die Ausgabe einfach übersprungen.

if / else

Mit else könnt ihr einen zweiten Codeblock ergänzen, der genau dann ausgeführt wird, wenn die Bedingung false ist:

int alter = 16;
if (alter >= 18) {
    System.out.println("Volljährig");
} else {
    System.out.println("Minderjährig");
}

Von den beiden Blöcken wird immer genau einer ausgeführt, nie beide und nie keiner.

Mehrere Bedingungen: else if

Mit else if könnt ihr mehrere Bedingungen nacheinander prüfen. Java prüft sie der Reihe nach und führt den ersten Block aus, dessen Bedingung zutrifft -- alle weiteren werden dann übersprungen.

int note = 2;
if (note == 1) {
    System.out.println("Sehr gut");
} else if (note == 2) {
    System.out.println("Gut");
} else if (note == 3) {
    System.out.println("Befriedigend");
} else {
    System.out.println("Ausreichend oder schlechter");
}

Java bricht bei der ersten zutreffenden Bedingung ab. Prüft ihr zum Beispiel zuerst note <= 4 und danach erst note == 1, würde die zweite Bedingung nie erreicht, weil die erste schon für fast alle Noten zutrifft. Allgemeine Bedingungen gehören deshalb meist ans Ende, spezifische an den Anfang.

Verschachtelte Bedingungen

Ihr könnt eine if-Anweisung auch innerhalb einer anderen verwenden -- das nennt man Verschachtelung. Das ist sinnvoll, wenn eine zweite Bedingung nur dann überhaupt geprüft werden soll, wenn die erste bereits zutrifft.

int alter = 20;
boolean hatTicket = true;
if (alter >= 18) {
    if (hatTicket) {
        System.out.println("Einlass gewährt");
    } else {
        System.out.println("Bitte Ticket vorzeigen");
    }
} else {
    System.out.println("Kein Einlass -- zu jung");
}

Alternativ lässt sich dasselbe hier auch mit einer einzigen Bedingung und dem logischen UND-Operator && aus dem letzten Abschnitt ausdrücken -- verschachtelte Bedingungen sind vor allem dann nötig, wenn die innere Bedingung eigene, unterschiedliche else-Fälle braucht.

Ausblick: switch

Wenn ihr eine einzelne Variable auf viele mögliche Werte prüft, wie im Beispiel mit den Noten oben, gibt es in Java auch die switch-Anweisung als Alternative:

switch (note) {
    case 1:
        System.out.println("Sehr gut");
        break;
    case 2:
        System.out.println("Gut");
        break;
    default:
        System.out.println("Ausreichend oder schlechter");
}

Das break beendet den switch-Block, default greift, wenn kein case passt. Für diesen Kurs reicht es, if/else sicher zu beherrschen -- switch lernt ihr hier nur zur Orientierung kennen, falls ihr es einmal in fremdem Code seht.

Ergebnis:

    Programmierung

    Legt für diesen Abschnitt ein Projekt Abschnitt6 an (siehe Abschnitt 0). Ihr arbeitet in einer einzigen main-Methode -- der Code für jede Aufgabe wird einfach ans Ende des bisherigen Codes angehängt, nicht ersetzt.

    Aufgabe 1 -- Einfache Bedingung

    Deklariert eine int-Variable temperatur mit einem selbst gewählten Wert. Gebt "Es ist warm" aus, wenn die Temperatur mindestens 25 Grad beträgt, sonst "Es ist nicht warm".

    "Mindestens 25" bedeutet 25 oder mehr, also der Operator >=.

    Aufgabe 2 -- Mehrere Fälle mit else if

    Deklariert eine int-Variable punkte (0 bis 100) mit einem selbst gewählten Wert und gebt je nach Punktzahl eine Note aus: ab 90 Punkten "Note 1", ab 75 Punkten "Note 2", ab 60 Punkten "Note 3", sonst "Note 4 oder schlechter". Testet euren Code mit mindestens zwei verschiedenen Werten für punkte, indem ihr den Wert änderst und erneut ausführt.

    Beginnt mit der höchsten Punktzahl (ab 90) und arbeitet euch mit else if nach unten durch -- so wie im Informationstext erklärt.

    Aufgabe 3 -- Verschachtelte Bedingung

    Deklariert eine int-Variable alter und eine boolean-Variable hatErlaubnis. Prüft zunächst, ob alter mindestens 16 ist. Ist das der Fall, prüft innerhalb dieser Bedingung, ob hatErlaubnis true ist, und gebt "Zutritt erlaubt" bzw. "Zutritt nur mit Erlaubnis" aus. Ist alter unter 16, gebt "Zutritt verboten" aus.

    Zwei -- eine äußere für das Alter, und darin verschachtelt eine innere für die Erlaubnis, ganz wie im Beispiel mit dem Einlass im Informationstext.

    Aufgabe 4 -- Fehler in Bedingungen erkennen

    Versucht nacheinander folgende Zeilen in einer separaten, testweisen if-Anweisung und notiert euch die jeweilige Fehlermeldung. Löscht jede Zeile wieder, bevor ihr die nächste ausprobiert:

    if (alter = 18) {
if alter >= 18 {
if (alter >= 18) {
    System.out.println("Volljährig")
}

    Überlegt euch jeweils, welche Regel verletzt wurde.

    Deklariert drei int-Variablen seiteA, seiteB und seiteC für die drei Seitenlängen eines Dreiecks. Bestimmt mit Bedingungen, ob das Dreieck gleichseitig (alle drei Seiten gleich lang), gleichschenklig (genau zwei Seiten gleich lang) oder unregelmäßig (alle Seiten unterschiedlich lang) ist, und gebt das passende Ergebnis aus. Testet euren Code mit mindestens drei verschiedenen Wertekombinationen, die jeweils einen anderen Fall abdecken.

    Überlegt euch zunächst alle Paare, die gleich sein könnten, und wie ihr diese einzelnen Vergleiche mit logischen Operatoren zu den drei Gesamtfällen zusammensetzt. Prüft dabei auch, in welcher Reihenfolge die Fälle abgefragt werden müssen.
